# Varoluşun Resmi Dilekçe Makinesi

> **Misyon:** Var olmak yeterli değildir. Var olmak *yazılı* olmalıdır.

Bu depo, evrenin en küçük vatandaşının (sizin) varlığını evrakla tescil etmek için yazılmış bilimsel bir mizah projesidir. Kod gerçekten çalışır. Hayatınızın resmiyeti size kalmıştır.

## Neden bu var?

Çünkü:
- Sabah kalkmak fiili durumdur ama evrak değildir.
- Gölge tapuya bağlanmadan kaybolabilir.
- Çay demlemek, varlığın en güçlü kanıtıdır.

## Kurulum

```bash
python3 dilekce_makinesi.py
```

Python 3 yeter. Başka hiçbir şey gerekmez. Evren zaten yüklüdür.

## Kullanım

1. Adınızı yazın.
2. Makine size evrak numarası üretsin.
3. Kararı okuyun.
4. Yine de var olmaya devam edin.

## Mimari (abartılı)

- **Katman 1:** Varoluş
- **Katman 2:** Dilekçe
- **Katman 3:** Damga
- **Katman 4:** Kuyruk (sonsuz)
